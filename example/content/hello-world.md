这是第一篇示例文章。正文使用 **Markdown** 编写，由 `markdown` crate
编译为 HTML，并套用站点模板与样式表。

## 支持的语法

asog 默认开启 GFM 扩展，因此表格、任务列表与删除线都可以直接使用：

| 特性 | 是否支持 |
| --- | --- |
| 表格 | 是 |
| 任务列表 | 是 |
| 脚注 | 是 |

- [x] 解析前置元数据
- [x] 生成标题锚点与目录
- [ ] 由你继续补充内容

## 代码块

```rust
fn main() {
    println!("hello, asog");
}
```

> 提示：标题的 `id` 由标题文本自动生成，重复标题会得到 `-1`、`-2` 后缀。
