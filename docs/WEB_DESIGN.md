# asog 网页样式设计说明

本文档描述 `asog` 生成站点的页面结构、视觉规范与样式表实现方式，
对应实现见 `src/page.rs`（模板）与 `src/assets/style.css`（样式表）。
样式表为纯 CSS，无预处理器、无运行时依赖。

## 1. 设计目标

1. **阅读优先**：正文使用衬线字体、受控行宽与舒适行高，长文阅读不疲劳。
2. **零依赖**：一份 CSS 文件即完成全部修饰，构建产物可直接用浏览器打开。
3. **自动适配**：跟随系统深浅色偏好，同时支持 `<html data-theme="dark|light">` 强制指定。
4. **可覆盖**：所有颜色、字体、圆角、阴影、行宽都集中在 `:root` 自定义属性中；
   源目录提供同名 `style.css` 时完全以用户样式为准。
5. **无障碍**：语义化标签、跳转链接、可见焦点、足够的对比度与可缩放字号。

## 2. 信息架构

| 页面 | 输出路径 | 内容 |
| --- | --- | --- |
| 首页 | `index.html` | 站点标题 + 站点描述 + `index.md` 正文 + 文章列表 + 标签云 |
| 文章页 | 与源文件相对路径一致 | 标题、日期/更新时间、标签、目录、正文 |
| 标签页 | `tags/<slug>.html` | 该标签下的文章列表 |
| 标签总览 | `tags/index.html` | 全部标签及数量 |

站内链接全部使用相对路径（由输出深度自动计算 `../` 前缀），
因此站点可以放在域名根目录、子目录或本地文件系统中直接打开。

## 3. 布局

```
┌──────────────────────────────────────────┐
│ sticky 页眉：站点标题 ······ 首页 / 关于 / 标签 │  backdrop blur + 1px 下边框
├──────────────────────────────────────────┤
│ main.wrap（max-width: 46rem，居中）        │
│   · 首页：hero + 正文 + 卡片列表 + 标签云   │
│   · 文章页：标题区 → 目录 → 正文            │
├──────────────────────────────────────────┤
│ 页脚：作者 · 使用 asog 生成                │
└──────────────────────────────────────────┘
```

- 单列布局，正文宽度 `--measure: 46rem`（约 70–80 个西文字符），
  左右内边距 `1.25rem`，主内容上边距 `2.5rem`。
- 页眉使用 `position: sticky` 配合 `backdrop-filter`，
  滚动时内容从半透明页眉下穿过（`@supports` 不满足时退化为纯色背景）。
- 文章卡片列表使用 CSS Grid（`gap: 1rem`），悬停时轻微上移并高亮边框。

## 4. 设计令牌

| 令牌 | 浅色 | 深色 | 用途 |
| --- | --- | --- | --- |
| `--bg` | `#f6f7f9` | `#0f1218` | 页面底色 |
| `--surface` | `#ffffff` | `#161b23` | 卡片、目录背景 |
| `--surface-muted` | `#f1f3f6` | `#1c222c` | 行内代码、代码块、引用 |
| `--text` | `#1d2330` | `#e6e9ef` | 正文文字 |
| `--text-muted` | `#616a7a` | `#9aa4b5` | 元信息、描述 |
| `--border` | `#e2e5ea` | `#262d38` | 分隔线与描边 |
| `--accent` | `#0b6bcb` | `#63b3ff` | 链接、标签、强调 |
| `--accent-soft` | `#e9f1fd` | `#16273a` | 标签底色 |
| `--radius` | `10px` | 同左 | 圆角 |
| `--measure` | `46rem` | 同左 | 内容行宽 |

字体栈：

| 令牌 | 取值 |
| --- | --- |
| `--font-sans` | 系统 UI 字体（含中文字体回退），用于标题、导航、表格、元信息 |
| `--font-serif` | `Iowan Old Style` / `Source Serif 4` / `Georgia` / `Songti SC` 等，用于正文 |
| `--font-mono` | 系统等宽字体，用于代码 |

阴影 `--shadow` 为两层柔和阴影，深色模式下改为黑色低透明度的浮起效果。

## 5. 排版层级

| 元素 | 规格 |
| --- | --- |
| 正文 | `1.06rem` / 行高 `1.75`，衬线字体 |
| 页面主标题（h1） | `clamp(1.7rem, 4.2vw, 2.35rem)`，字重 700，字距 `-0.015em` |
| 首页标题 | `clamp(1.75rem, 4vw, 2.25rem)` |
| 卡片标题（h2） | `1.25rem`，行高 `1.35` |
| 正文 h2 | `1.5rem`，下边框分隔，上边距 `2.2em` |
| 正文 h3 | `1.25rem` |
| 元信息 | `0.9rem`，`--text-muted` |
| 标签 chip | `0.82rem`，胶囊圆角 |
| 小屏（≤ 32rem） | 正文降到 `0.97rem`，标题改为居中，内边距收窄 |

## 6. 组件

- **页眉导航**：固定顺序为「首页 → `title_bar: true` 的页面 → 标签」；
  自定义项使用页面标题作为链接文字，按源文件路径排序（可用 `01-about.md` 控制顺序）。
  当前所在页面通过 `aria-current="page"` + `.is-active`（加粗、正文色）标记，
  标签子页也会把「标签」标记为当前项；链接允许换行，标题过长时自动折行。
- **站点图标**：`<link rel="icon">` 指向源目录 `assets/logo.*`（优先级
  svg → png → ico → webp → avif → jpg/jpeg → gif），`type` 由扩展名推断；
  没有该文件时完全不输出 icon 声明，也不占用任何额外请求。
- **文章卡片**：标题（链接）、日期/更新时间、标签、摘要，圆角 + 阴影 + 悬停动效。
- **标签 chip**：`--accent-soft` 底 + `--accent` 字，悬停反色；标签总览页附带数量。
- **目录**：`toc: true` 且标题数 ≥ 2 时渲染，按标题级别缩进（h3 缩进 1rem，h4+ 缩进 2rem）。
- **标题锚点**：标题自动获得 `id`，并在标题末尾插入 `#` 链接；
  默认透明，鼠标悬停或键盘聚焦时淡入，屏幕阅读器通过 `aria-hidden` 忽略。
  标题设置 `scroll-margin-top: 4.5rem`，跳转时不会被 sticky 页眉遮挡。
- **代码**：行内代码带浅色底与描边；代码块独立圆角容器并横向滚动。
- **引用**：左侧 3px 强调色竖线 + 浅色底 + 右侧圆角。
- **表格**：全宽、单元格描边、表头浅色底，使用无衬线字体保证可读性。
- **图片**：居中、圆角、柔和阴影，`max-width: 100%` 自适应。

## 7. 深色模式

样式表通过两套选择器提供同一组深色令牌：

```css
@media (prefers-color-scheme: dark) {
    :root:not([data-theme="light"]) { /* 深色令牌 */ }
}
:root[data-theme="dark"] { /* 深色令牌 */ }
```

- 默认跟随系统偏好；用户显式设置 `data-theme="light"` 时不再受系统影响。
- `color-scheme: light dark` 让滚动条、表单控件等原生 UI 与主题一致。
- 若后续加入主题切换按钮，只需在 `<html>` 上切换 `data-theme` 属性即可。

## 8. 无障碍

- 语义标签：`header` / `nav` / `main` / `article` / `footer`，标题层级连续。
- 首个可聚焦元素是「跳到主内容」链接，键盘聚焦时才出现在左上角。
- 导航、文章列表、目录、标签区均带 `aria-label` / `aria-labelledby`；
  当前页面用 `aria-current="page"` 标注。
- `<time datetime="...">` 提供机器可读时间；文章 `lang` 随站点语言设置。
- 正文与背景对比度满足 WCAG AA；链接除颜色外还有下划线。
- 关键跳转目标设置 `scroll-margin-top`，并对 `:focus` 保留可见样式。

## 9. 打印

打印时隐藏页眉、页脚、目录与锚点，隐藏装饰性阴影，正文改为 11pt 黑字白底、
链接保留下划线，便于直接打印或以 PDF 归档。

## 10. 自定义方式

1. **整体替换**：在源目录放置 `style.css`，asog 不会写入内置样式表，站点完全使用你的样式。
2. **局部覆盖**：在自己的样式表中覆盖 `:root` 令牌即可，例如：

   ```css
   :root {
       --measure: 60rem;
       --accent: #b45309;
       --font-serif: "Noto Serif CJK SC", serif;
   }
   ```

3. **扩展标记**：`--no-raw-html` 关闭时可关闭原始 HTML；默认允许在 Markdown 中
   直接书写 `<div class="...">` 等标签以配合自定义样式。

## 11. 后续可扩展方向

- RSS / Atom 订阅与 `sitemap.xml`；
- 客户端搜索（构建时生成索引 JSON）；
- 代码高亮（构建期生成高亮 HTML，避免引入运行时 JS）；
- 主题切换按钮（复用 `data-theme` 机制 + `localStorage`）；
- 上一篇 / 下一篇导航与相关文章推荐。
